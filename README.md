# Punto Universitario

Este proyecto consiste en un sitio web informativo desarrollado como parte de la tarea académica de Estándares W3C.

Su objetivo es compartir información y recomendaciones generales para estudiantes universitarios.

## Páginas del sitio

- index.html: página principal.
- servicios.html: información y recomendaciones para estudiantes.
- contacto.html: formulario para consultas y sugerencias.

## Carpetas y archivos

- css/estilos.css: contiene los estilos del sitio.
- js/script.js: contiene las funciones interactivas.

## Tecnologías utilizadas

- HTML
- CSS
- JavaScript

## Accesibilidad

Durante la revisión del sitio se realizaron algunas mejoras:

- Se agregó un enlace para saltar directamente al contenido principal.
- Se mejoró la navegación mediante teclado.
- Se agregó un indicador visible al seleccionar enlaces, botones y campos.
- Se utilizaron etiquetas para identificar los campos del formulario.
- Se incorporaron atributos ARIA en los elementos interactivos.

Este sitio fue elaborado con fines académicos. El formulario de contacto es una demostración y no envía información a un servidor.
## Herramientas de revisión

Para revisar el sitio se utilizaron las siguientes herramientas:

- Nu HTML Checker: validación del código HTML.
- W3C CSS Validator: revisión de los estilos CSS.
- WAVE: evaluación de accesibilidad.
- Lighthouse: evaluación de accesibilidad y calidad del sitio.
- NVDA: pruebas con lector de pantalla.
